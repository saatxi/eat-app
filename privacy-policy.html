EatApp Privacy Policy

Your data never leaves your phone

Effective and last updated: August 28, 2026

In short: EatApp collects nothing. There are no accounts, no analytics, no ads, and no tracking of any kind. The only network request the app makes is a plain download of a public, static restaurant list — nothing about you or your device is sent anywhere.

What EatApp is

EatApp is a personal project by Albert Ferran: a read‑only browser for a curated list of restaurants he has actually visited — name, cuisine, address, rating, and price range. There is no way to add, edit, or delete restaurants from the app itself; the list is maintained separately and published as a single data file.

Data we collect

None. EatApp has no sign‑up, no login, no user profile, and no analytics or crash‑reporting SDK embedded in it. Nothing you do inside the app — searching, filtering, sorting, opening a restaurant, tapping refresh — is recorded, transmitted, or shared with anyone, including the developer.

No accounts No analytics No ads No tracking SDKs No location access

The one network request

Tapping “Refresh Data” downloads a single static file (a small SQLite database of restaurants) over HTTPS from a public GitHub address. It is the same file for every install of the app — it is not personalized, and the request carries no identifying information beyond what any standard HTTPS request includes at the network level (such as your IP address, visible to GitHub's servers as with any web request). The app itself reads nothing from that response except restaurant rows, and writes nothing back.

That downloaded data is stored only in the app's local database, on your device. It is never uploaded, synced to a server, or shared with any third party.

Permissions

PermissionWhy it's needed
Internet Required to download the restaurant list file described above. Not used for anything else.
Network state Lets the app check whether a connection is available so it can skip a doomed download attempt and show a clear message instead. It does not reveal what network you're on to anyone.

EatApp requests no other permissions — no location, no contacts, no storage, no camera, no microphone.

Children's privacy

EatApp is not directed at children and collects no personal information from anyone, regardless of age.

Changes to this policy

If this policy ever changes — for example, if a future version of the app adds a feature that involves data collection — this page will be updated and the “last updated” date above will change accordingly.
